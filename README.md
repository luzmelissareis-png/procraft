# ProCraft fix: APK build branch

Pushing this branch builds the ProCraft Android app (arm64) from upstream commit 7f73ab1 plus the GPU
memory fix and the photo-import memory fix, as a separate app ("ProCraft fix", app id
`io.github.artcraftandroid.procraft.fix`) that installs next to an existing ProCraft.
The APK is attached to a pre-release under Releases. Safe to delete this branch afterwards.
